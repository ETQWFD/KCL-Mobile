# KCL（手机版 / Android）

KCL 是基于 FCL-Team **Fold Craft Launcher** 的独立第三方再发行版本，用于在 Android 上运行 Minecraft Java 版。

- 本版本由 **龙腾OS / ETC Team** 修改维护，按“现状”提供，不附带任何担保。
- 完整保留 FCL-Team 上游署名；FCL 遵循 **GPL-v3** 协议，本版本同样遵循 GPL-v3。
- 更新检查与公告地址已切换到本仓库（ETQWFD/KCL-Mobile），不再使用原作者的更新通道。
- 本软件不运营 Minecraft，也不运营任何多人服务器。未成年人充值、服务器封禁、道具纠纷、支付退款等请联系对应服主或 Microsoft/Mojang 官方支持。
